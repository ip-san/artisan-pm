# A1-28 設計メモ: CSV インポートのカスタムフィールド列・遅延付き関連・`unique_id`

状態: `blocked(要承認)`。バックログが「設計メモ必須(認可コンテキストの扱い)」と指定している行。

## 背景

Redmine の課題インポート(`IssueImport`)は次を扱う。本アプリの `ImportIssuesJob::mapRowToAttributes()` は 1 行 1 課題で、下の 3 つはいずれも未対応。

1. **カスタムフィールド列**: 列ごとにカスタムフィールドを割り当て、形式に応じて値を解釈する。
2. **関連(遅延付き)**: `relation_follows` / `relation_blocks` などの列に「課題 ID」または「`unique_id`」を書き、`precedes`/`follows` には遅延日数(`follows:3` 形式)を付けられる。
3. **`unique_id`**: ファイル内で行を識別するキー。親課題・関連の参照先を「同じファイルの別行」で書けるようにする。参照先の行が後ろにあるときのため、全行を作成した後で親/関連を解決する 2 パスにする(Redmine は `unique_id_map` を持つ)。

## 現状と制約

- ジョブは行ごとに `IssueService::create()` を呼び、失敗行は `errors` に積んで続行する。親参照は「同じプロジェクトの既存課題 ID」のみで、ファイル内の別行は指せない。
- `Issue::relevantCustomFields()` は認可コンテキスト(`auth()->user()`)でフィールドの可視/編集可否を判定する。キュー実行時のジョブには認証済みユーザーがおらず、判定が実行ユーザー(`$this->import->user`)ではなく空になる。
- CSV 読み込みは `array_map('str_getcsv', file(...))` の行単位で、引用符内の改行を持つ値(長文のカスタムフィールド)を壊す。カスタムフィールド対応の前にここを直す必要がある。

## 判断が要る点

1. **認可コンテキスト**:
   - A. ジョブ内で実行ユーザーを `Auth::setUser()` して既存コードをそのまま使う(推奨しない。リクエスト外で暗黙のグローバル状態を持つ)
   - B. `relevantCustomFields()` などが `?User $viewer` を明示的に受け取れるようにする(推奨。呼び出し元は既定で `auth()->user()`)
   - C. ジョブ側で「実行ユーザーのロールで編集可能なフィールド」を別に計算する(重複実装になる)
2. **2 パスの持ち方**: 1 パス目で `unique_id → 課題 ID` の対応を作り、2 パス目で親・関連を設定する(推奨)。`unique_id` が重複する行、参照先が存在しない行、循環する親子は行エラーにする。途中で失敗した行の子/関連は「親を持たない」ではなく「行エラー」にする(黙って落とさない)。
3. **関連の作成方法**: `IssueRelation` を直接作らず、既存の関連作成経路(循環・プロジェクト間・重複の検証と `rescheduleFromRelation()`)を通す(推奨)。検証に落ちた関連はその行の警告として記録する。
4. **マッピング画面**: カスタムフィールド列と関連列を割り当てる UI が要る(現状は固定の項目名のみ)。項目数が増えるため、列見出しとの自動突き合わせ(名前一致)を入れるか。

## 推奨案と分割

1. **A1-28a**(S): CSV パーサを `fgetcsv`/`SplFileObject` に替え、引用符内の改行と BOM を正しく読む(先行修正、テスト付き)。
2. **A1-28b**(M): `relevantCustomFields()` に閲覧者引数を追加(B 案)し、カスタムフィールド列のマッピングと値の検証・保存を追加。
3. **A1-28c**(M): `unique_id`、2 パスの親解決、関連列(遅延付き)を追加。

## 影響範囲

`app/Jobs/ImportIssuesJob.php`、`resources/views/livewire/issues/import.blade.php`(マッピング UI)、`HasCustomFields` / `Issue::relevantCustomFields()`(B 案の場合)、`IssueImport` のマッピング保存形式。工数インポート(`ImportTimeEntriesJob`)は別行 A2 系で扱うため対象外。
